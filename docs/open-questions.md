# Open questions

The system makes a choice for each of these so that work can go on. The brand kit ([chilichip-brand #1](https://github.com/chili-chip/chilichip-brand/issues/1)) may change them. They are tracked in [chilichip-brand #8](https://github.com/chili-chip/chilichip-brand/issues/8).

| Question | Default for now | Changes if decided otherwise |
| --- | --- | --- |
| **Green.** Logo green, or the mint green Chili Platform uses today (`#7dffb3`)? | Logo green: `leaf` and its tints. | `leaf-bright` and the `link`, `focus` and `success` roles. |
| **Orange.** Keep the orange (`#ff6b35`) from Chili Platform? | Dropped. It is not in the logo. | A new support colour and the `danger` role. |
| **Wordmark.** Do we draw the name? | "chilichip" in Syne ExtraBold next to the logo. | [Logo and name](logo.md#the-name). |
| **One-colour logo.** For print, stamps, engraving. | None yet. Use the colour logo on a neutral plate. | New files in `logo/` and a row in the logo table. |
| **Pixel logo.** 16, 32 and 64 px. | Script-made drafts. | [Small screens](small-screens.md#logo), and the player icon in [#3](https://github.com/chili-chip/chilichip-brand/issues/3). |
| **Fonts.** A new font is being picked in [#2](https://github.com/chili-chip/chilichip-brand/issues/2). | Syne, Inter, IBM Plex Mono, Press Start 2P. | The `font` tokens and [Typography](typography.md). |
| **Final logo file.** `logo/logo-workspace/` has older versions with other colours. | `logo/chilichip-logo.svg` is the master. | The three brand colours, and everything derived from them. |
